# ==========================================================================
#  Зависимости сервера и клиента распознавания лиц (dlib из исходников)
# ==========================================================================
#  ВАЖНО ПРО ПОРЯДОК УСТАНОВКИ
#
#  1) Сначала фиксируем setuptools (сборка dlib из исходников ломается
#     на setuptools>=70 — «module 'setuptools' has no attribute ...»):
#
#        python -m pip install --force-reinstall "setuptools<70"
#
#  2) Затем ставим всё остальное:
#
#        python -m pip install -r requirements.txt
#
#  Автоматически оба шага выполняет ./install.sh (Linux/macOS) или
#  install.bat (Windows) — рекомендуется именно он.
#
#  Если компилировать dlib не хочется (нет cmake/g++ или сборка падает),
#  используйте предкомпилированные колёса:
#
#        ./install.sh --prebuilt   (или)  pip install -r requirements-prebuilt.txt
#                                  &&  pip install --no-deps "face_recognition>=1.3.0"
#
#  ОЗВУЧКА (TTS):
#    * В Docker: Silero TTS (пакет `silero`) уже в образе сервера (docker/Dockerfile.server).
#    * На хосте (Linux): sudo apt install espeak-ng — запасной движок.
#    * Нейросетевой русский голос на хосте (как в Docker):
#        ./install.sh --tts        (или вручную:)
#        pip install --index-url https://download.pytorch.org/whl/cpu torch torchaudio
#        pip install "silero>=0.5" scipy
#    * Windows/macOS: ничего ставить не нужно — используется SAPI5/NSSpeech
#      через pyttsx3.
# ==========================================================================
