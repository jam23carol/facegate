# ==========================================================================
#  Зависимости БЕЗ компиляции dlib (предкомпилированные колёса)
# ==========================================================================
#  Вместо dlib (сборка из исходников: cmake + C++-компилятор, 5–15 минут)
#  используется dlib-bin — готовые бинарные колёса для:
#      Linux x86_64/aarch64 (glibc и musl), Windows amd64, macOS arm64/x86_64,
#      Python 3.10 – 3.14.
#
#  Установка (рекомендуется скриптом):
#      ./install.sh --prebuilt          (Linux/macOS)
#      install.bat --prebuilt           (Windows)
#
#  Вручную — три команды, порядок важен:
#      python -m pip install --force-reinstall "setuptools<70"
#      python -m pip install -r requirements-prebuilt.txt
#      python -m pip install --no-deps "face_recognition>=1.3.0"
#
#  Почему --no-deps: пакет face_recognition объявляет зависимость `dlib`,
#  а dlib-bin предоставляет модуль dlib под другим именем дистрибутива.
#  Без --no-deps pip начал бы собирать dlib из исходников.
#
#  Нейросетевая русская озвучка (как в Docker) ставится отдельно:
#      ./install.sh --tts
# ==========================================================================
